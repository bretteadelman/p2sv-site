# Website UI kit — pushtostart.ventures

Three click-through screens built from the component library:

- **HomeSheet.jsx** — the 552px framed sheet: Masthead band, name + phonetic, Key Reports callout, Contact form.
- **ReportPage.jsx** — the 590px report column: Headline, StatRow, BarChart, CardGrid, CTA Callout, SheetFooter.
- **HandoutView.jsx** — the US-letter Handout, scaled to fit, with print.
- **data.js** — copy and figures from the P2SV Med Spa Market Brief.

Flow: home → click "Med Spa Market Brief" → report → "Print handout". The wordmark returns home.
Recreated from the P2SV Design System artifact screenshot; the live site was not available, so the home-sheet copy is limited to lines that appear in the source.
