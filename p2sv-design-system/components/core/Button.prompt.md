Square small-caps call to action; use for the one action on a surface (usually "Start a conversation").
```jsx
<Button>Start a conversation</Button>
<Button variant="outline">Read the brief</Button>
<Button variant="link" arrow href="#contact">Start a conversation</Button>
```
- `variant`: primary (ink) · outline · link (underline thickens 1→2px on hover)
- `arrow` adds ↓. No icons, no rounded corners, no shadows.
